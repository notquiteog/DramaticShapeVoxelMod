# Original environment materials

`hoenn-hedge-leaves.png` is original generated artwork commissioned for this
mod's Petalburg hedge models. It contains no copied ROM pixels, screenshots
or user reference art. A native source strip was a visual style reference only. Generated with the built-in imagegen tool on 2026-10-17.
The native GBA hedge supplied the color direction and blocked footprint only.
The leaf material is shared by every section, with world-scaled UVs and no
per-tile top/front color substitution. `Gen3Hedges.lua` authors the mesh.

Final generation prompt (the earlier detailed-leaf candidate was rejected and
is not shipped):

> Create ONE NEW production game texture swatch. The supplied image is a STYLE AND PALETTE REFERENCE ONLY: native GBA hedge tiles, showing their smooth light green tops, plain broad green masses, and tiny square-pixel scallops. Do not reproduce that reference sheet, its labels, dark background, or object outlines. Output a square full-bleed seamless diffuse texture for the TOP of a clipped hedge. It must look very close to the smooth broad light-green center of reference tile 24C. Dominant color exactly #84C563 covering at least 90 percent of the texture. Only tiny restrained sparse square-pixel clusters in very nearby greens #7DBD5C and #8BCB6B supply slight clipped-foliage detail. Pixel-art language, intentionally simple, calm, flat, clean, low contrast. Use crisp tiny square pixel clusters, not realistic leaves. No pointed leaves, no oval leaves, no leaf veins, no vines, no individual drawn leaves, no painterly rendering, no photographic or detailed foliage. No broad dark patches, no stripes, no color bands, no gradients, no shadows, no lighting, no outline, no border, no text, no labels. This is an ORIGINAL MATERIAL swatch, not an illustration or object render. Preserve the reference's restrained original pixel-art feel.

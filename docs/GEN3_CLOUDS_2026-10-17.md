# Soft cumulus and one shared sky material

The optional `KFP SKY = LAYERED` cloud path now uses `Clouds.lua`. The actual
standalone white lattice was the embedded KFP sky payload: three stippled decks,
each split into five bands. `Sky.lua` does not draw clouds, and the older
`SkyLayer.lua` decks remain disabled. There is one cloud owner; the embedded
payload still owns its existing stars, birds, aircraft and rainbow options.
No Wilds or other companion is required or changed.

The new material has smooth optical coverage and normal-lit, rounded crowns,
irregular deterministic silhouettes and placement, warm dawn/dusk lighting,
night thinning and darker extra weather coverage. A closed hemisphere samples
one repeating spherical field, so turning through the longitude seam cannot
reveal a card edge. Cloud generation uses no global gameplay RNG. The texture,
mesh and shader are cached, allocation failures are contained, and every draw
restores graphics state without writing terrain depth. Indoor/forest eligibility
and the existing sky option remain authoritative; defaults are unchanged.

Desktop material storage is 2 MiB; the capability-selected mobile/console atlas
is 512 KiB. The cloud pass submits one draw and 1,152 vertices instead of fifteen
draws and 5,616 vertices. The shader uses one atlas lookup for clear weather and
two for extra storm/rain/snow coverage, without a ray march or per-cloud loop.
These are submission/resource counts, not measurements of GPU execution time.

`Clouds.glsl` exports `cloudAt(direction)`, and `Clouds.reflection()` exports the
same cached image, palette, sunlight direction, weather coverage and wind phase
only while its current view is active. Native Gen3 water can sample this exact
material rather than generating a competing cloud field. A missing/inactive
sky yields no reflection state. Legacy water remains outside this integration.

## Native review

Official Gen1Recomp 0.3.89, Linux source shell, isolated QA identities, standalone
Battle Art, NVIDIA RTX 5060 Ti / OpenGL 3.3 / driver 615.71.09. No gameplay save
was overwritten. The outer NVIDIA GLX vendor selection was verified in each
runtime log; earlier llvmpipe ownership captures are not timing evidence.

`tools/qa/gen3-cloud-review.lua` reviews FireRed and LeafGreen in Pallet Town
at (10,9), plus Emerald/Ruby/Sapphire in Oldale Town at (10,9), camera `1ST`,
1280x720, render distance16, horizon/birds/aircraft/rainbows off, AA off, spatial
scale1, world curve off, water off. Each edition has ten inspected native views:
clear OFF/ON, side view, both sides of the +/-pi seam, dusk, night OFF/ON,
storm and Oak's/Birch's Lab indoors. All five runners pass, 50 captures total.
No lattice or longitude gap remains; cloud OFF and indoors leave no active
cloud reflection. The unchanged star field is still present under LAYERED at
night. Neighboring buildings, HD-2D actors and native room UI remain intact.

Focused LuaJIT tests cover filled/soft material, finite deterministic generation,
no gameplay RNG changes, day/weather palettes, closed geometry, one cached draw,
resource reuse, OFF/indoor reflection lifecycle, graphics restoration and partial
allocation failure. The KFP regression asserts its embedded cloud decks stay
disabled while the host cumulus runs. Lua compile and `git diff --check` pass.

## Warm submission comparison

The same driver supports `QA_CLOUD_BENCH=1`: one process at a time, same NVIDIA
hardware and fixture, 90 warm frames followed by 240 measured frames per case.
It wraps the public KFP draw function and records CPU submission median/p95,
actual graphics draw-count deltas, legacy mesh counts and host cloud counts.
Frozen 1.49.0 is the before case. The candidate is the after case. Whole-frame
performance is assessed separately by the surface benchmark; these small scope
timings do not establish an FPS or GPU-speed guarantee. Android/GLES hardware
performance was not measured.

The following CPU submission values are milliseconds (median / p95):

| --- | ---: | ---: |
| firered / day-LAYERED | 0.0505 / 0.0860 | 0.0339 / 0.0641 |
| firered / night-LAYERED | 0.1045 / 0.3332 | 0.1032 / 0.3011 |
| firered / storm-LAYERED | 0.0930 / 0.1203 | 0.0753 / 0.1241 |
| emerald / day-LAYERED | 0.0574 / 0.1226 | 0.0334 / 0.0709 |
| emerald / night-LAYERED | 0.1148 / 0.3427 | 0.1053 / 0.3119 |
| emerald / storm-LAYERED | 0.1013 / 0.1911 | 0.0924 / 0.1155 |

Daytime cloud submission fell from 15 draws to 1 (93% fewer), and from 5,616
vertices to 1,152 (79% fewer). Night totals include the unchanged 25-draw star
field: 40 draws before, 26 after. OFF remains zero draws. The cloud CPU scope
gets cheaper, but unchanged star work dominates its night result; storm p95
varies between editions. No GPU-time or whole-frame FPS claim follows from
these measurements. All four serial runners exit0, 20 measured segments.
